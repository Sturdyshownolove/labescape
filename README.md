# 🧪 Lab Escape: Chemical Protocol

A fast-paced cyber/laboratory-themed memory matching puzzle game built with vanilla HTML5, CSS3, and JavaScript.

## 🎮 Features
- **Level 1: Entry Room (Pairs)** - Match chemical element pairs to bypass quarantine security.
- **Level 2: Lab Room (Triplets)** - Advanced puzzle matching compound triplets under time pressure.
- High-score tracking via `localStorage`.
- Cyberpunk dark UI with smooth animations and alert notifications.

## 🚀 Getting Started
Simply open `index.html` in any modern web browser or host on GitHub Pages / Vercel / Netlify.
